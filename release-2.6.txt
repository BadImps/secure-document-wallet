My Vault 2.6 adds accurate companion previews for Word documents. Word upload is now a guided two-file flow: select the untouched DOCX, then select a PDF exported from that same document. My Vault encrypts the original DOCX unchanged and uses the PDF pages for the in-app preview. Open Word continues to open the exact original file. DOCX files without a PDF companion display a secure Word file card instead of a misleading reconstructed preview.
